## Keys

Press `F1` in a match for this list on screen. These are the defaults; the title's SETTINGS screen moves any of them.

### Camera, selection and orders

| Key | What it does |
|---|---|
| `ARROWS` | PAN THE CAMERA |
| `MIDDLE-DRAG` | PAN |
| `WHEEL` | ZOOM 0.5X TO 3X |
| `= -` | ZOOM IN, OUT |
| `MINIMAP` | CLICK JUMPS, RIGHT-CLICK SENDS |
| `LEFT-CLICK` | SELECT, DRAG FOR A BOX |
| `DOUBLE-CLICK` | ALL OF A KIND ON SCREEN |
| `SHIFT` | ADD TO THE SELECTION; QUEUE AN ORDER |
| `CTRL+0-9` | SAVE A GROUP, 0-9 RECALLS |
| `.` | NEXT IDLE VILLAGER |
| `RIGHT-CLICK` | MOVE, GATHER, BUILD, RALLY |
| `T` | STOP |
| `C P G B L` | TRAIN AT A BARRACKS, RANGE, STABLE |
| `RIGHT-CLICK` | ON AN ENEMY: ATTACK |
| `RIGHT-CLICK` | ON A TOWER OR TOWN CENTER: GARRISON |
| `T` | AT A BUILDING: ALL OUT |
| `A, P` | ATTACK-MOVE, PATROL, THEN CLICK |
| `Q E I K` | STANCE, AGGRESSIVE TO PASSIVE |
| `Z` | NEXT FORMATION |
| `DELETE` | DISMISS |
| `SPACE` | PAUSE |
| `[ ]` | SLOWER, FASTER |
| `F3` | EDGE SCROLL ON, OFF |
| `F2` | HUD SIZE |
| `F5` | QUICK SAVE |
| `HOME` | HOME: THE TOWN CENTER |
| `TAB` | EYES, IN A REPLAY |
| `F1` | THIS LIST, ON SCREEN |
| `ESC` | CANCEL, DESELECT, MENU |

| `L` | STABLE 150W (TOOL) |
